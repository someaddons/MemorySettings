# Memory settings

[![CurseForge Downloads](https://cf.way2muchnoise.eu/full_526901_downloads.svg)][curseforge] [![Minecraft Versions](https://cf.way2muchnoise.eu/versions/526901.svg)][curseforge] [![Download on CurseForge](https://img.shields.io/badge/Download-CurseForge-F16436?logo=curseforge&logoColor=white)][curseforge]

Memory settings is a small utility for checking Minecraft's memory settings at launch and warning the user when there is an issue.

Configuring the right amount of memory is important to not have stuttering/freezing issues while playing the game.

## Installation

1. Install the required mod loader.
2. Download the mod from the official CurseForge page.
3. Place the `.jar` file in your `mods` folder.

> This mod is officially distributed only through CurseForge. Downloads from other websites may be outdated, modified, or unsafe.
